Plex
Media server for browsing and accessing your library. Primary source for recently downloaded content. plex.tv
Find your access token at plex.tv/claim or by going to Settings → Account in the Plex web app. If Plex is enabled, it will be the primary source for "Recently Downloaded" content, falling back to Radarr/Sonarr/Readarr if unavailable.
